# Trump Communication x Market Event Study

Static research dashboard for exploring Trump communication events and market reactions across QQQ/NASDAQ, SPY/S&P 500, RTX, VIX, and VXN.

This deployment bundle includes only the browser app and processed research data needed for GitHub Pages. Raw source files and build scripts are intentionally excluded from this public site bundle.

Open `index.html` through GitHub Pages or any static web server.
